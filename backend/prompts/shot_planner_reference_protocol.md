本次请求的参考目录协议（适用于所有 subjects.visible_prop_keys 和 scene.visible_prop_keys）：

- 固定场景与本页环境条件分开读取：snapshot.scene 提供建筑、布局、材质、固定陈设和固有颜色，snapshot.scene_conditions 提供本页时段、天气、光照与氛围。framing_notes 保留本页条件，与本页脚本文字一致；参考原图只约束固定空间，不能覆盖本页条件。未指定项保持未指定，不从原图推断。此规则同样适用于自定义 ShotPlanner Prompt。
- 本页局部状态协议始终适用，包括使用已保存的自定义 ShotPlanner Prompt 时：只读设定提供人物固定样貌、当前绑定造型和场景基准，本页结构化脚本（及 snapshot.page_script）提供当前画面变化；没有跨页事件提取或状态重放。
- 单一时刻协议始终适用：可以有动势和多人同时动作，不能有先后动作。action、pose、expression、gaze、visible_state 与 framing_notes 必须对应本页脚本选定的同一瞬间；不按动词数量限制动作，不添加动作过程、视线转移、表情先后变化或动作前后的两个状态。已完成动作只保留脚本明确的当前可见结果，不因 summary 或 dialogue 的叙事含义扩展新动作。
- subjects.visible_state 只写本页脚本明确、在当前镜头实际可见的湿污、破损、伤痕、卷袖等人物或衣物局部状态，按 character_key 分清归属，不复述或改写固定外貌、基础造型；没有变化时为 ""。section_context 的 current_state、emotion、temporary_changes 是分段剧情提示，不得直接当作本页已经发生的状态。背面镜头不补写不可见的面部伤痕或五官。
- 这两个字段用于选择已建档物品的参考原图，不是本页所有可见物品或持有物的清单。

- 场景设定及页面脚本可能包含目录外的普通剧情物品。这些名称不会自动成为合法的参考目录 key；即使物品明确可见，也不能把目录外 key 加入 visible_prop_keys。
- 普通物品仍须按脚本保留在人物 action、pose 或场景 framing_notes 的自然语言描述中。不要为了满足目录限制删除画面中实际存在的包、工具、纸张或容器，也不要用合法目录 key 替换另一个物品。
- 只从上述合法列表中选择本镜头实际可见的物品。每个 key 在整份 ShotPlan 的所有 subject 和 scene 中最多出现一次；一个列表内也不能重复。人物持有且可见时归入对应 subject；已放下且可见时归入 scene。人物只是看向、指向、靠近或负责观察桌上的物品，不构成该人物持有，不应把同一物品再填入 subject。
- 以本页结构化脚本确定画面中的唯一瞬间及物品当前持有人，不要凭站位、观察动作或通用设定把物品移给他人。持有本身不等于当前镜头可见；不根据历史 held_props、prop_owners 或前页事件推演归属。遇到交接或放下动作，应选择与本页脚本一致的一个位置，不能同时描绘动作前后的两份物品。
- 场景设定、人物设定与物品目录描述只说明稳定外观和可能存在的物件，不会覆盖本页局部状态。不得把这些描述复制为本页新增物品或新增动作；例如人物正托举唯一木盒时，不要另外在桌面添加一个木盒，也不要凭场景描述让随身邮包被放下。

- 对静态场景中的物件清单、可能摆放的位置和过往状态，只保留当前画面适用的内容。普通非目录物品照常保留在 framing_notes 或人物 action/pose 中；目录物必须与 visible_prop_keys 的位置一致。封闭容器只描述其外观、闭合状态和当前所在位置，不枚举不可见的内容物。

# 分页脚本共同业务语义

本协议用于规划、编写和审查，统一解释输入设定的作用范围。

- 固定地点定义与本页画面分开：版本 2 场景只锁定建筑、布局、材质、固定陈设和固有颜色；本页人物、普通剧情物品、门窗开合、湿污破损等局部状态以及 scene_conditions 不属于固定地点定义。
- 场景 negative_constraints 只约束固定地点身份，例如不能把露天连廊画成封闭房间、不能把办公室改成住宅。旧目录中的“禁止固化天气/时段/光照”“禁止出现任何角色”“禁止出现临时物品/人物私物”等，是固定地点定义的编写范围说明，不是整页禁令；本页允许出现已绑定人物、剧情物品、天气、灯光和氛围。不能据此要求空景、清空本页条件或删除剧情。
- 上述作用范围不能用来忽略真正的固定约束：地点建筑与布局、角色身份与固定外貌、唯一配件及明确的角色禁止改写项仍必须保持一致。
- scene_conditions 的 time_of_day、weather、lighting、atmosphere 分别填写；每项未指定时为空字符串，可以只填写其中一项。未指定不代表禁止出现，也不要求四项一起填满或一起清空；只检查已填写条件与本页文字是否冲突。
- 每页是同一空间、同一时刻的单幅画面。允许迈步、奔跑、挥拳、举手、回头或开门中的一个瞬间，以及同一时刻的多人动作；禁止需要先后发生的动作链或同时存在动作前后两种状态。
- “只剩”“已经合上”“戴着”“仍然”等表达当前结果或状态，不因它们暗示过去就认定为先后动作。判断依据是本页要求画出的全部动作和状态能否同时成立，不能根据关键词或动词数量机械判断。
- 人物与道具在同一空间内左侧/右侧、前景/背景的站位，以及普通景别和相机视角，都是合法构图；只有实际拆成多个时刻、多个完整空间或页内分镜才违反单幅画面约束。
- 新规划的 page_plan 逐页给出 scene_key 与 beat，地点必须出现在本段 scenes 中；缺少地点时规划阶段补充新地点，不能把缺失场景留给 Writer。
- 已锁定分段的 description 是剧情功能与节奏参考。历史规划没有 page_plan，或其文字地点超出当前可用场景时，在可用地点表达相同核心剧情与当前结果，不把未提供的地点或逐字站位当成 Writer 必须满足的条件。不得新增 key、混画多个空间或擅自修改锁定设定。
- page_plan 中的地点是自动生成的规划参考；人工重绑后的复审以页面实际绑定场景及当前文字为准，不仅因它与原规划地点不同就退回。仍需检查核心剧情、固定设定和单幅画面是否成立。
